# Neverland Lab (Student Version)

This repository provides the **Neverland cyber-physical simulation lab** used in the CSS module.

---

## Prerequisites

- Docker
- Docker Compose
- Internet connection (for first run only)

---

## First week

### Clone the repository:

git clone https://github.com/carolsworld/neverland-lab-student.git

cd neverland-lab-student

### Make the script executable:

chmod +x scripts/*.sh

### Start the learning environment:

./scripts/start-teaching.sh

Once started, open http:127.0.0.1:8080

### Stop the learning environment:

./scripts/stop.sh

## Second week

### Start the assessment environment:

./scripts/start-assessment.sh

### Stop the assessment environment:

./scripts/stop.sh
